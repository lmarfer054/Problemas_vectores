Ejercicio Práctico

Dados los puntos \(A(-5, 2)\) y \(B(-2, 7)\), halla tres vectores equipolentes al vector \(\vec{a} = \overrightarrow{AB}\).

Primero, calculamos las componentes del vector fijo original \(\overrightarrow{AB}\) restando extremo menos origen:

\[ \vec{a} = \overrightarrow{AB} = B - A = (-2 - (-5), \, 7 - 2) = (-2 + 5, \, 5) \implies \pmb{\vec{a} = (3, 5)} \]

Para hallar vectores equipolentes (vectores con el mismo módulo, dirección y sentido), basta con situar este mismo vector libre \((3,5)\) eligiendo tres puntos de origen aleatorios. Sumamos las componentes al origen para obtener cada extremo:

  • Ejemplo 1 (Origen en el centro): Elegimos \(C(0,0) \implies D = (0+3, \, 0+5) \implies \pmb{\overrightarrow{CD} \text{ con } D(3,5)}\)
  • Ejemplo 2 (Cuadrante positivo): Elegimos \(E(1,2) \implies F = (1+3, \, 2+5) \implies \pmb{\overrightarrow{EF} \text{ con } F(4,7)}\)
  • Ejemplo 3 (Desplazado en X): Elegimos \(G(-1,1) \implies H = (-1+3, \, 1+5) \implies \pmb{\overrightarrow{GH} \text{ con } H(2,6)}\)
