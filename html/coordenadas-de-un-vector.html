Coordenadas de un vector

Texto

Problema 1

Halla las coordenadas del vector \(\overrightarrow{MN}\), siendo sus puntos extremos: \[ M(-6, 2) \qquad N(4, 8) \]

\[ \overrightarrow{MN} = N - M = (4 - (-6), \, 8 - 2) = (4 + 6, \, 6) \implies \pmb{\overrightarrow{MN} = (10, 6)} \]

Problema 2

Un vector tiene extremos inicial y final \(A(2, -1)\) y \(B(3, 5)\) respectivamente. Hallar las coordenadas de \(\overrightarrow{AB}\).

\[ \overrightarrow{AB} = B - A = (3 - 2, \, 5 - (-1)) = (1, \, 5 + 1) \implies \pmb{\overrightarrow{AB} = (1, 6)} \]

Problema 3

Un vector \(\overrightarrow{AB}\) tiene componentes \((5, -2)\). Hallar las coordenadas de \(A\) si se conoce el extremo \(B(12, -3)\).

\[ \overrightarrow{AB} = B - A \implies (5, -2) = (12 - x_A, \, -3 - y_A) \]

Separamos las componentes en dos ecuaciones lineales:

  • Componente X:   \(5 = 12 - x_A \implies x_A = 12 - 5 \implies x_A = 7\)
  • Componente Y:   \(-2 = -3 - y_A \implies y_A = -3 + 2 \implies y_A = -1\)

Reuniendo las coordenadas, obtenemos el punto inicial: \(\pmb{A(7, -1)}\).
